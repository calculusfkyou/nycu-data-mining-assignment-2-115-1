\section{Task Definition \& Data}
\label{sec:data}

\paragraph{Anomaly definition.}
This is an image anomaly detection task: industrial inspection photographs, where the challenge is
spatial texture, background clutter and very small defects.
The unit of detection is one image of one product.
An image is \emph{normal} if the object meets specification, and \emph{anomalous} if it shows a surface
defect (scratch, burn, colour spot, crack, bubble) or a structural defect (bent, misplaced or missing
part); Figure~\ref{fig:samples} shows examples.
The median ground-truth defect covers only 0.20\% of the image (10th / 90th percentile 0.03\% / 1.67\%).

\paragraph{Dataset and labels.}
We use VisA \citep{zou2022spot} (CC BY 4.0, \url{https://github.com/amazon-science/spot-diff}):
$N = 10{,}821$ images, 9,621 normal and 1,200 anomalous, of 12 objects with 34 defect types in three
groups: complex structure (pcb1--4), multiple instances (candle, capsules, macaroni1--2) and single
instance (cashew, chewing gum, fryum, pipe fryum).
Every tier receives a $224 \times 224 \times 3$ input ($D = 150{,}528$); Tiers~2 and~3 turn it into
pretrained patch features (\S\ref{sec:method}).
Image labels and pixel masks come from the dataset authors; we use the masks only for analysis.
Subtle defects may carry label noise that we cannot quantify, and all capsules anomalies share one
defect label (bubble).
The setting is semi-supervised: models are fitted on normal images only, and a few labelled anomalies
are used only to choose thresholds and hyperparameters.

\paragraph{Split and preprocessing.}
We fix one split (seed~0) for all tiers (Table~\ref{tab:data}).
Images are resized directly to $224 \times 224$ and normalised with ImageNet statistics.
We avoid the usual resize-256 plus centre-crop-224, which on val masks would remove 4.1\% of defect
pixels on average and 22.9\% for macaroni2.

\paragraph{Class imbalance.}
The anomaly : normal ratio is 1 : 8.02 overall (11.1\% anomalies), 1 : 3.98 in val and 1 : 1.34 in
test, all far above a realistic production prevalence.
Predicting every image as normal gives 57.2\% test accuracy, and 99.0\% at a 1\% prevalence while
catching no defect, so we never report accuracy; a classifier trained with plain cross-entropy would
drift towards the same rule.
We counter this by fitting on normal images only, by using PR-AUC, which depends on the anomaly rate
\citep{davis2006relationship,saito2015precision}, as the primary metric, and by converting each
operating point to the precision expected at a deployment prevalence $\pi \in \{1\%, 5\%\}$:
\begin{equation}
  \mathrm{prec}_\pi = \frac{\pi \cdot \mathrm{TPR}}{\pi \cdot \mathrm{TPR} + (1-\pi) \cdot \mathrm{FPR}}.
  \label{eq:prec-pi}
\end{equation}
